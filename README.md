# TableCraft: Minecraft Plugin

TableCraft is a Minecraft plugin that adds table functionality to your server. It allows players to create and interact with tables, enhancing the gameplay experience with additional features and customization options. This plugin is designed to work with PaperMC and provides a variety of commands and events to manage and utilize tables effectively.

## Install

1. Download the TableCraft plugin JAR file from the [releases page](https://github.com/EnderDevelopment/TableCraft/releases).
2. Place the JAR file in the `plugins` folder of your Minecraft server.
3. Restart your server to load the plugin.

## Use

1. **Creating a Table**: Use the `/table create` command to spawn a table at your current location.
2. **Interacting with Tables**: Players can interact with tables by right-clicking on them. This will open a GUI where they can customize the table's appearance and functionality.
3. **Managing Tables**: Use the `/table remove` command to remove a table from the world.
